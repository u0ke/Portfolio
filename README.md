# ice — Vanilla Portfolio

This is the React portfolio converted to plain HTML, CSS and JavaScript.

## Files

- `index.html` — all page markup
- `css/style.css` — all styling and responsive layout
- `js/script.js` — theme toggle, mobile menu, scroll spy, project filtering, reveal animations and copy-email behavior

## Run

No npm packages are required.

You can simply open `index.html` in a browser.

For local development, VS Code + Live Server is optional.

## Original conversion source

Converted from the `jdily` branch of `u0ke/Portfolio`.

The content follows the supplied portfolio design/reference PDF and the existing React implementation.
