## ✨ Philosophy

Inspired by the **Helium browser** — a UI so calm it disappears.  
Deep indigo gradients. Stark white typography. Electric cyan accents.  
Every pixel is intentional. Every animation is subtle. The code is the design.

---

## 🚀 Features

### 🌐 Public Site
| Feature | Description |
|---------|-------------|
| **Animated Hero** | Per-letter staggered name reveal with smooth entrance |
| **Dynamic Profile** | Avatar, bio, location, age, and fun facts (gym, PC, code, coffee) |
| **Skills Matrix** | Animated progress bars for hard skills; pill chips for soft skills |
| **Project Showcase** | Responsive cards with image, tech stack, live demo & GitHub links |
| **Education Timeline** | Clean academic rows with status badges |
| **Blog Section** | Article excerpts with dates |
| **Contact Form** | Minimalist underline inputs; submissions routed to admin inbox |
| **Theme Switcher** | Toggle between **Helium** (indigo/cyan) and **Vercel** (pure black/white) |
| **Fully Responsive** | Optimized for mobile, tablet, and desktop |
| **AOS Animations** | Smooth, scroll-triggered reveals with reduced-motion support |
| **Accessibility** | Focus rings, semantic HTML, keyboard navigation |

### 🔐 Admin Dashboard
| Feature | Description |
|---------|-------------|
| **Secure Login** | Session-based auth (8-hour expiry) |
| **Dashboard Overview** | Live stats, quick actions, recent messages |
| **Profile Manager** | Edit name, bio, avatar, contact links, fun facts & education |
| **Skills Manager** | CRUD for hard & soft skills with real-time sync |
| **Project Manager** | Full CRUD via modal editor with image, stack, links |
| **Blog Manager** | Full CRUD for posts with date picker |
| **Message Inbox** | Read, mark as read, delete contact submissions |
| **Site Settings** | Title, accent color, and default theme |
| **Credential Manager** | Change username & password securely |
| **Data Backup** | Export / Import full portfolio as JSON |
| **Reset** | One-click restore to factory defaults |

## 🛠️ Tech Stack

- **HTML5** — Semantic, accessible markup
- **Tailwind CSS** (CDN) — Utility-first styling with custom indigo/electric palette
- **Vanilla JavaScript** — Zero dependencies, zero build step
- **AOS** — Lightweight scroll animations
- **localStorage** — Persistent data layer for the admin
- **JSON** — Canonical data format for portability
